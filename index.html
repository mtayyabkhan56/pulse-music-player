# 🎧 Pulse — Modern Web Music Player A beautiful, responsive browser-based music player built with HTML, CSS, and vanilla JavaScript. ## ✨ Features - 🎵 Play, pause, next, and previous - 📂 Import local audio files - 🔀 Shuffle and repeat modes - ❤️ Favorite tracks - 🔎 Search and filter your music library - ⏩ Playback speed controls - 🔊 Volume and mute controls - 📊 Animated audio visualizer - ⌨️ Keyboard shortcuts - 📱 Responsive interface - 🌙 Modern dark theme with accent colors - 🔒 Local playback without an account or API key ## 🚀 Getting Started 1. Clone or download this repository. 2. Open `index.html` in a modern browser. 3. Click **Add music**. 4. Select audio files from your device. 5. Enjoy your music! ## 🌐 Live Demo Once GitHub Pages is enabled, add your deployed website URL here. ## 🛠️ Technologies - HTML5 - CSS3 - JavaScript - HTML Audio API - Web Audio API ## 🔐 Privacy Imported audio is played locally in the browser. Music files are not uploaded to a server by this application. The current library is session-based, so re-import your files after refreshing the page. ## 📄 License Released under the MIT License.
